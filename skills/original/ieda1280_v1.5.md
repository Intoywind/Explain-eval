# IEDA1280 四轮期中速通

## 目标与执行方式

用户以速度为优先，约八小时从零走完期中范围。可带一张双面 A4 Cheatsheet（总结纸），不以背熟公式为目标。每轮给一份能直接阅读、开着追问的完整知识清单，完成四件事：

1. 认得课程词汇与概念，知道它实际指什么；一个点讲通后前进。
2. 明白公式里各个量、运算和条件在描述什么；不要求背诵或完成与考题无关的证明。
3. 直接接课程原题，看出题面要求与从已知条件到答案的操作。
4. 看过题目后，把概念、公式、操作和用途串起来，形成能判断下一步的直觉。

“知识清单”是包含解释和题解的短讲义，不是名词与公式目录。**每轮本身就是独立复习模块，一次交付整轮，不拆成必须逐次回复“继续”的碎片。**

用户只要求创建或修改 skill 时，完成 skill，不自动开始第一轮。用户说“开始第一轮／给第二轮清单”就交付指定轮；问一个点就在对应编号下解答，不重讲整轮。

## 四轮划分与阅读节奏

准备每轮前，读 [完整范围与材料](references/scope-and-sources.md) 的对应轮次。输出前必须读 [三项自检](references/quality-gates.md)。

| 轮次 | 独立主题 | 内容边界 |
| --- | --- | --- |
| 1 | Decision foundations and Project analytics（决策基础与项目分析） | L1 全部概念层内容＋L2 项目、网络图、CPM、赶工、PERT |
| 2 | Facility location decisions（设施选址） | L3 单设施选址、集合覆盖、选址与分配及前置概念 |
| 3 | Inventory analytics（库存分析） | L4 EOQ、敏感性、再订货点、数量折扣、报童模型及前置概念 |
| 4 | Facility layout decisions（设施布局） | L5 布局类型、CRAFT、线平衡、并行工作站；末尾完成四轮用途串联 |

- 原定每轮约一小时阅读只是安排参考；完整文档交付后由用户控制阅读速度，阅读与追问时间可跨轮调配。用户明确能快速阅读讲得懂的材料，不能用统一阅读速度估计替用户裁剪内容，也不承诺八小时内掌握。
- **先按配额写，全文精简后仍装不下必要内容才允许超额。** 默认每轮常规目标为 5000–7500 个中文字，上限 7500；讲完整后少于 5000 不凑字。统计整份交付文档的可见中文字符，包括标题、翻译、表格内中文、公式内中文说明、轮末串联、总结纸候选和自检；英文、公式符号与纯数字不计入中文字配额，但仍纳入全文阅读负担与去冗余检查。统计方法及脚本见三项自检文件。
- 生成前按范围列出各单元新增的概念、条件、操作及对应题目，并分配单元字数预算：先给轮末等共用内容留量，再以剩余配额除单元数作起点，按实际难度调整。概率、PERT、报童等可多分，纯概念单元少分，各部分预算合计不超过整轮配额。单元超预算先检查可否精简或在整轮内调剂，不直接放宽整轮上限。
- 超额必须同时满足：必要内容确实无法在配额内讲完整；全文已逐段检查并删尽可删的重复背景、同义解释、重复计算、重复题干和空段，继续删会损失具体知识、条件、原题翻译、必要步骤或理解所需的因果连接。两项都满足后才增加最少必要字数，并在自检中列实际字数、超额数及具体保留理由；“内容难”“用户读得快”本身不是豁免理由。不能为守配额牺牲完整性，也不能以完整性为由跳过全文精简。
- 按考查机制合并同类例题，不把题源候选全部堆进清单。相同机制的补充题可以引用已讲方法，只展开条件差别、改变的步骤、必要中间量与答案；仍须有完整相关英文原题和翻译。不同操作不能因共用模型名称就省略，例如离散需求累加概率与正态需求查表都要实际演示。
- 第一轮的 L1 按教师概念层深度讲清，主要计算留给 L2；不为 L1 硬配大计算题，也不以十分钟之类的配额删概念。
- 四轮独立可打开：所需前置概念在本轮有最短解释，不要求读者记得前轮某符号。
- 不安排额外必做第五轮，不默认增加两小时模拟卷。用户可直接进入下一轮，不以背诵、闭卷复述或测验达标为通行条件。

## 范围与题源

范围依据最新明确考试通知，再对照范围内讲义逐项覆盖。已核实本次为 L1–L5；**Sample paper（样卷）只提供题型示例，不能根据样卷出现或未出现来删知识点。** 教师只作概念介绍的内容按该深度讲，不能扩展成未教算法或新专题。

实际读取对应课程原件；AI 总结只用于找材料。原件和勘误入口见材料参考。已核实的同一考试信息不每轮重新查邮件；有新通知、范围冲突或跨学期复用时再核对。

题源标签准确区分 Past paper（历年真题）、Official sample paper（官方样卷）、Course exercise（课程原题）、Adapted exercise（改编题）、Self-written example（自编例子）。目前归档的是官方样卷及课程原题，没有已确认年份的历年期中真题。优先用可核实官方原题；不能因用户统称“真题”就改标签，也不因此停止教学。

按不同考查机制选题。每个计算模型至少有一次原题应用；一道综合原题可覆盖多个相连知识点。纯概念点可用选择题或直接判断连接用途，不硬配大计算题。缺少某点原题时，用明确标为自编的同场景最小例子补用途，记录题源缺口；不可编造英文原文。

## 学生可见语言硬标准

语言质量是这套速通能否执行的核心验收条件；算对答案、覆盖范围或守住字数都不能代替语言合格。以下规则覆盖清单、追问回答、标题、表头、结论句、题解、轮末串联及总结纸候选内容。先把关键因果讲明白，再按字数规则删除冗余；不能剪掉关键一步来换取字数合规。

1. **英文在前，中文紧随。** 专有名词、模型名、题干常见表述写 English（中文）。不能只在开头词汇表双语，后文只给中文或英文。缩写首次给英文全称与中文含义，后续可写 CPM（关键路径法）这种已定义的双语缩写。变量可保留符号，含义表必须双语并带单位。
2. **英文原题先完整呈现，再翻译与拆解。** 原题区保持原文，不插解释或改写；相邻中文翻译保留关键英文。相关小问、选项、数据表、图、单位、条件全部保留。只选独立小问时标“原题节选”，带齐依赖题干，不冒充整道原题。
3. **所有解释落到实际对象。** 指明题中谁或什么东西、什么时段、能改变什么、不能违反什么。说清每个量在数什么、测什么；算法每步选了谁、减掉什么、更新哪张表。纯概念也要落到原件里的具体决定、选项、后果和限制，不能只做词典翻译。禁止用一串未解释术语定义另一个术语。
4. **直觉来自可看见的关系。** 先讲实际事实，再接公式。活动必须等所有前置活动完成，就先说“还差其中一个没做完也不能开工”，再解释取最大完成时间。分子、分母、加减乘除的理由对上实际数量。每道题决定下一步的关键判断必须用具体对象、时间点或数量摊开；若有多个不同分岔，逐个解释。读者应能指出每一步用了哪条已知事实、结果交给下一步做什么。沿用本题的工厂、活动、订单、设施和需求点，禁止无关类比或另换复杂故事。
5. **指代明确、理由贴着动作。** 不用“这个、它、该值、显然、易得、根据定义”代替对象与理由。每个“因此”有前文事实支撑；计算后说明结果用于哪一步。普通连接词不强行翻译。
6. **具体且不过度展开。** 用最短完整解释讲到能辨认对象和用途，不把简单含义扩展成长篇“本质”描述。用户表示明白就前进；缺失前提用一两句或本题一步计算补齐。

英文原题区按第 2 条保持原文，因此不逐词插中文；紧随的翻译与讲解区执行第 1 条。这是原文保真的位置区别，不是放宽双语标准。

## 先会解题，再对应符号

概念理解与实际动作是主线；一般数学表达不能成为开始做题的门槛。每个方法先用 English（中文）和一句具体意思说明，再给可迁移的操作顺序，最后只保留执行或识别所需的公式。不要用一串函数、下标、双重求和把已经能直接相加的题目重新变难。

- 明确区分三类用途：**理解**（认概念与判断条件）、**计算**（按条件和算法算数，可用等价的直接展开）、**建模**（题目明确 Formulate / Define / Model 时，写变量、目标、约束）。Determine / Find 不自动要求重写一般模型；题目指定算法、表格或证明仍须执行，不能以“按常识”省略必要步骤。
- 每个展示的公式必须说明“在算什么、何时适用、得到结果后做什么、答题是否需要原样写”。每个字母、下标、函数与运算记号就近给出 **English name（中文含义与实际对象）＋单位**。函数名是量的简称，不是要求学生随意创造定义；区分题目给定的费用关系与自行设置的决策变量。
- 先交代通用问题与做法，再代入本题；不能只有某一道题专用的释义。求和要给可手写的展开或逐项相加法；原式只起概括作用时标明“可直接展开算，不必先重写模型”。必须采用模型的规则，不等于必须照抄符号形式。
- 教学表格、题目给的数据表、题面要求填写的答题表分开标注。无指定格式时给最短充分的考场写法，不把辅助大表、全部中间解释变成强制抄写要求；也不能只剩最终答案而没有比较依据。
- 综合题可以跨知识单元，但解题操作必须连续；进入后续小问时重述当前已知状态和要解决的缺口。更优方案不能凭空出现：说明怎样从已有方案发现可替换项或比较项。
- 课程原件明确教学或练习的内容不能仅因样卷没出现就断言不考。可删掉范围外推导与不帮助完成题目的一般化符号；在清单中将课内的纯概括表达后置为识别材料。总结纸按实际题源压缩，省略某个原式时保留必要的等价操作与条件，不把省略说成“不考”。

R2.6 的标准起手是“试设施数与客户分组 → 每组用适用的选址方法找位置 → 各客户权重乘距离相加 → 加题给开设费用 → 比较”。双重求和放在这些动作之后且仅用于识别或建模；分组计数单列为“问方案数量时使用”，小规模先列举。`123/4` 是分组，`[6,12]` 是坐标区间，`(6,12)` 才是一个二维坐标；首次出现须说清。

**总结纸须独立于旧例题使用。** 保留“题面出现什么条件 → 为什么选此法 → 如何取数和运算 → 如何更新／比较 → 报什么”的通用逻辑；不依赖过去的编号、图、数值、解答或用户记忆，不把旧题答案片段当作操作说明。四轮讲义仍用完整原题教学，这条是考场总结纸的交付区别，不是删除课内题型。

用户要求双面 A4 时，读 [解题式总结纸](references/practical-cheatsheet.md)。用户要求“按新 skill 自检”时，除原有三项检查外，必须按本节检查公式负担、题目动词、可迁移步骤与考场写法；不能只核算答案和字数。

## 每轮知识清单的固定结构

使用 R1.1、R1.2 等稳定编号，方便直接问“R1.3 第二步”。顶端写范围、阅读时间估计、可点击目录。正文按知识依赖排列，禁止先用后定义。

### 每个知识单元

1. **实际问题与对象**：这一节决定什么；有哪些对象；给什么、求什么。标题含 English（中文）概念名。
2. **术语与概念**：每个词落到明确对象、数量或动作；解释本题含义与易混量，补所需前提。
3. **怎样动手与必要公式**：先给可执行的一般步骤和一句实际含义，再决定是否需要原式；公式出现时逐符号给英文名、中文对象、单位及条件，用本题数字展开关键一步，并标明理解／计算／建模用途。只做概括的符号式后置，不强制推导或背诵。
4. **官方原题应用**：按下节顺序处理。多个相连知识单元可接同一综合题，注明编号，避免重印。
5. **使用连接**：三至五句串起“题目出现什么条件 → 要决定什么 → 用什么关系 → 怎么操作 → 答案拿来做什么”。给一个会改变下一步的具体条件变化即可，不强制追加练习。

### 每道题的内容与顺序

以下是需要交代的内容，不是必须凑齐的九个标题。相邻说明可合并，但保留“英文原题 → 翻译 → 拆解题意 → 解答”的阅读顺序；选法理由、必要假设和步骤理由放在使用前或紧邻处。

- 来源与位置：身份、文件链接、PDF 页码、题号。
- English original question（英文原题）：完整相关题干、小问、选项、表图。
- Translation（中文翻译）：保留限定、否定、比较方向、单位；关键术语英文加中文。
- Read the question（拆解题意）：先补题干、表头、选项或翻译中新出现而本轮尚未解释的术语，再讲谁/什么、已知量、待求量、限制条件；解释 Formulate（建立模型）、Determine（求出或确定）、At least（至少）等实际出现的要求。原题区保留原文，不能为补定义改写原题。
- Why this method（为什么用这个方法）：把题面条件对应到本轮已经解释的概念和关系。
- Assumption（采用的假设）：题面没写、但课程模型需要的前提就地说明；不能把自己补的条件说成题目已给。没有额外假设时省略这一段；已在拆解或选法处解释的前提不再重复。
- Solution（答题过程）：每步给动作与紧邻理由，可复核中间表、算式和单位，最后给答案；禁止列一个公式后跳到数字。题目要求填表时，所有待填列都要有去处，不能为了紧凑少一列。区分一般算法规则、启发式选择理由和本题实际核算，不把直觉解释写成最优性证明。
- Exam steps（考场写法）：只列答卷应写的必要条目、算式、图表和结论，区分题目强制格式与辅助表；无填表要求时给直接展开或简表写法；不复述 Solution（答题过程）的解释，不让用户自己猜哪些解释要写进答案；不编造教师未提供的逐步分值。
- What changes the method（什么条件会改变做法）：指出真实限制或易错分岔。选择题解释正确项及其他选项主要混淆，重复错误可合并。

Multiple-choice question（选择题，MCQ）用紧凑格式：来源 → 完整英文原题及全部选项 → 翻译 → 拆解（新术语、正确项理由、主要干扰项与必要运算）→ 答案。不套九段标题，不省掉决定答案的条件或理由。

同一道综合题跨本轮多个单元时，首次出现给本轮会用到的完整英文题干、表图、全部相关小问及翻译，标明小问去向；后续用可点击编号接续具体小问，不重印题干。若整题并未全部收录，准确标“原题节选”。另一轮引用时仍补齐相关题干与翻译，保证该轮可独立阅读。

### 图表必须实际呈现

- 题目给出的图属于原题信息：嵌入清晰原图或原页并核对。答题要求画图时，真正交付图，不能只写“如图”或只给 PDF 链接；不要把题面已经给图误称为题目要求重新画图。
- 原 PDF 的图用 PDF 渲染工具导出所需页为 PNG；确需裁图时保留箭头、标签、坐标、单位和题目条件。文件存到本轮文档旁的 `assets/`，例如 `四轮知识清单/assets/L4_原题_p18.png`，注明源 PDF 页码。Obsidian 文档用相对图片链接，聊天中展示用绝对路径；保存后打开实际图片检查清晰度与内容，不仅检查路径存在。
- 网络图、前置关系图可用 Obsidian 支持的 Mermaid 代码块，附任务的直接前置关系列表；箭头活动图还要明确活动所在箭头与零时间虚活动。核对节点、方向、标签和全部连线；直接与间接关系不能混淆。原题图不得为了简化而悄悄删边，另绘的简化图须说明用途。
- 布局网格用能保留位置、面积与邻接关系的网格表或清晰 SVG/PNG，标坐标、尺寸及单位；不把只表达连接关系的 Mermaid 图充作空间布局。附可核算的格位或坐标数据，并检查显示可读。

读取后重算关键结果，再与官方解答核对。OCR 不清的图表、负号、上下标回到原 PDF，不脑补。原题笔误照录并就地注明；自己的解答给正确计算，区分教师答案与独立核算，不能把改正后题干冒充原文。区分精确值与四舍五入的近似值；未经官方说明，不承诺“老师接受”“这样写也给分”或其他评分口径。

### 轮末收束

- 用做过的题把“实际需求 → 概念 → 公式 → 操作 → 决策结果”接成读得通的线，不再堆孤立公式。
- 给简短题型识别与第一步对照，突出何时换模型或重算。
- 给 A4 Cheatsheet（总结纸）候选条目：双语概念短释、题面触发条件、执行步骤、必要公式及逐符号含义、是否必须照式写、高危易错点；不附加背诵任务。候选条目不等于可打印 A4 成品；用户要求成品时按总结纸参考执行。
- 第四轮额外完成全课用途串联，讲清项目安排、选址、订货、布局分别决定什么，哪些能连接、哪些不能混用；不全文重印前三轮。
- 最后给三行“本轮自检”实际结果和简短核对表，标准见质量门槛文件。自检是助手的输出检查，不是给用户加考试。

## 追问、保存与续接

用户开着清单追问时，先定位编号和卡点，用对应题目的对象或数字解释；新出现的前提立即补一句。结尾只给必要接回位置，不反复要求复述，不顺带扩展下一章。“明白／下一点”就前进；要求更底层就拆到具体数量、先后顺序与动作。

唯一正式 skill 源文件位于课程 Obsidian AI工作区中的本包，安装入口指向本包。清单保存到同一 AI工作区的“四轮知识清单”目录；每轮一份稳定文件，追问造成的必要修订更新对应段落。不覆盖原始课程 PDF。保存失败如实说明，不宣称落盘成功。

仅交付 skill 时不生成四轮讲义或总结纸成品。区分“清单已交付”“用户明确说理解”“独立作答证据”；助手自检通过不等于用户掌握，沉默不等于已经学完。
