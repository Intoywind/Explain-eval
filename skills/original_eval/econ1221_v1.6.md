# ECON1221 期中速通｜四轮高效版

参考用户指定的 COMP2711 正式版流程，按 ECON1221 的闭卷选择题改造。**高效优先，给四轮完整推进的空间**：中文讲清概念，保留关键英文；把理解、记忆、公式衔接和做题放在同一模块，不把大量证明、长篇背景或重复阅读当作学习进度。

验收看三件事：用户能理解“这是什么、为什么”；能根据条件决定“用哪条关系、方向是什么”；能闭卷提取关键区别与起手动作。笔记写完或讲解完成，不等于用户已经独立掌握。

## 启动与边界

1. 用户指定知识点或题目时直接进入，保留原计划接回点；只要求制作／修改 skill 时，不启动教学。
2. 本次已确认范围是 Topics **1–7，到 Gold 为止**，教材对应 Ch10、11、13、16，另有课堂扩展。Topic 3 宏观思想史、Topic 4 商品市场与乘数、Topic 6 IS–LM、Topic 7 Gold 都不能因缺少对应教材作业而省略。Topic 8、9 和 PS5、6 不在本次期中范围内。范围更新以用户提供或核对到的最新明确课程通知为准。
3. 已确认考试为 **2026-10-29，40 道选择题／80 分钟，闭卷，不允许笔记，可用简单计算器**。考试安排保存在材料指引，不每次重复。记忆卡是考前复习材料，不是可携入考场的 cheatsheet；不继承 COMP2711 的单面 A4 规则。
4. 默认四轮，但**不默认四小时一轮，也不擅自假定用户还有十六小时**。已有剩余时间就分配；未给时间时展示四轮目标与相对权重，直接开始首个模块，不先追问或做诊断。压缩方式见计划；不声称任何固定时长保证掌握。
5. 笔记用于定位与解释，不把先前 AI 总结当作教师原文或掌握证据。只在真正影响交付时问缺失的最小文件，不让用户重新上传全部材料。

**展开深度跟随教师**：以教师实际讲解、课程材料和指定题目的要求为准。老师只提名称或一句定义，就按该深度交代，不自行增加公式、专题、统计细节或背诵要求。教材用于讲清本课已有内容和完成指定题目；只补理解当前内容、避免误用所必需的最短前提，用户明确追问时再针对性解释。四轮计划与已有补充笔记是定位工具，不是扩大教学深度的依据；自编题同样只覆盖已确认课程内容的应用缺口。

## 节奏与篇幅

- 正常每次交付一个完整模块；开轮只加轮次目标、模块清单和时间分配（若总时间已知）。用户说“继续”就进入下一模块，不再确认；最后一模块后接本轮秋高。
- 普通模块中文解释目标约 **700–1200 字，常规不超过 1600 字**；“压缩／快一点”目标约 **450–800 字**。必要题干、公式与联立计算不为字数截断，但不能借此重复长解。纯记忆或辨析模块可以更短，复杂模型按可理解性适度放宽。
- 第③段按**独立易错机制的覆盖**决定题量，不固定为一道代表题或一个变式。优先用一个共同题干的多个短问覆盖不同疏漏；同一错误机制的重复题、重复公式和装饰性背景先删。篇幅紧张时压缩重复说明，不为字数漏掉会改变答案的条件；独立机制确实较多时可适度放宽。不要把“简短”做成术语列表。
- 追问先直接补当前卡点，不重讲整模块、不强制加测；补完标回到哪里。用户要求回顾可只给记忆卡与秋明；要求跳过则标待补后继续，不冒充完整交付。
- 不安排必做的大块独立刷题时段，不以“先答完才能继续”卡住学习。可给一句自我复述提示并附核对点；只有用户实际作答才记录独立能力证据。完整 40 题／80 分钟模拟只在用户要求时安排，不能挤掉默认四轮的内容。

## 每模块四段

### ① 概念与机制：先理解，再命名

用一句话说明本模块解决的问题，再用最小例子或因果链解释。新概念先说对象和日常含义，再给“中文（English）”；后续讲解、解题与记忆卡继续自然使用核心英文，不只在首次括注后全部换回中文。新符号当场说明。

- **概念题**：优先用结论式短句说明“指标统计什么 → 本项属于／不属于 → 给定条件下有什么结果”，用常识讲清理由和是／不是的边界，再用分类表收束。能用两三句讲清时不默认展开长数值例子；需要时再用最小例子解释，不能用分类表或中英术语清单代替解释。说明定义边界，再对照最容易混淆的另一概念，如投资与买股票、准备金与资本、货币与财富。
- **公式题**：同时给符号原式与中文公式；中文版本保留分式、求和、乘除等运算结构，把变量换成对应的中文含义，例如“消费者物价指数＝Σ(商品当年价格×该商品固定数量)／Σ(商品基年价格×该商品固定数量)×100”。不能用一段口头操作说明或符号释义表代替中文公式。首次出现时就近说明“算什么、符号与单位、已知到未知、条件、怎样接到前一关系”；给必要的短推导，能用定义一两步推出的，不另列成一堆必须背的新公式。
- **机制／政策题**：写“初始变化 → 谁的行为改变 → 哪个市场／曲线改变 → 均衡结果”，同时说清什么固定、什么内生。图形先给坐标轴，再区分沿线移动与整条线位移。
- **史实／Gold**：按“人物／制度或事件 → 主张／约束 → 解释什么现象”组织，保留讲义要求的辨认点，不长讲生平，不把一般市场关系写成必然涨跌。

尤其防止：实际与名义混用；流量与存量混用；GDP 核算恒等式与计划需求均衡混用；封闭经济 S=I 套到任意经济；实际／名义利率及百分数单位混用；固定货币供给与固定利率混用；只依赖利率的投资与同时依赖收入的投资混用。具体勘误见材料索引，用到时核查原页。

### ② 怎么用 · 背什么

紧凑给四项，不再复制①的整段解释：

- **使用步骤**：题面信号 → 判条件／口径 → 列关系或因果链 → 算结果／排选项，通常不超过四步。
- **必须背**：本模块真正需要立即提取的定义边界、方向、英文信号与少量基础公式；每条带最短条件。零散补充术语说明应记到“能辨认”还是“能计算／推导”的程度，以材料和教学用途分配精力，不凭感觉断言不会考。
- **理解后推出**：明确哪些量可以由前述关系现场导出，以及从哪一式开始，避免把所有变形式都当背诵负担。
- **考前记忆卡**：最多三条“触发条件 → 结论／第一步”，只放本模块已解释内容。这张卡不携入考场，不新增未讲知识。

### ③ 题目应用与选项辨析

目标是补齐“只读①②仍可能没意识到的应用疏漏”，不是展示已经讲过的公式能代入一次。检查已知数据的不同给法、条件变化、单位／口径、逆向判断、边界与选项陷阱；仅选与本模块有关的机制。

每个已识别、会导致不同错误答案的机制，至少用一处可检查的题面或反例说明。优先把它们合并到同一原题的多个小问；新增题必须带来尚未覆盖的误区，单纯换数字的不增加。数量由缺口决定，不机械凑满“几道题”，也不因已有一道代表题就停止检查。①②中已充分展示且不会新增理解的同类算题可省略。

每一题都先给已知条件与明确的待求事项（计算什么、判断哪句话或选择哪项），再给解答；只有易错点标题、公式或结论不算题目。共用数据的短问可以引用前面的题干，只补改变的条件和本问任务，不重复整张表，但不能省略实际问句。

主例给完整题面与解法；其余短辨析保留完整必要条件、最短可核查计算／推理、明确结论，并点出“容易错在哪里、为什么错”。不必为每个短问重复四个小标题，但不能退化成只有结论的易错点清单。题解使用的新概念与公式必须已在①②或此前教学中解释；发现先修缺口就先补概念，再出题，不能在答案里突然引入。重点是覆盖不同错误机制，不能宣称少量题穷尽所有可能考题。

优先使用可自足的课程题／已核实真题；题源不足可用标明“自编练习／基于课程数据改编”的短题补应用，不为等待历年卷中断四轮。**不得将课件题、教材题、改编题或自编题称为历年真题。**

1. **题面与来源**：给文件／章节、题号、PDF 页等实际定位。原题保留所选完整题目／自足小问的英文题干、公共条件、数据、图表标签与全部必要选项，不能用中文译文替代英文原题。随后用中文解释决定答案的词句，例如 relatively、domestically produced、holding other things constant。自编／改编题也优先给英文题面，清楚标明身份；确需重述时标“英文题意重述”，不得冒充原文。只读到解答册时，不能反推一段文字冒充原题。
2. **读题与调用**：翻译决定答案的关键词，指出题目给什么、问什么；说明哪个条件让②的关系可用。
3. **完整解法**：给最短可复核过程或因果链；概念选择题可用“定义＋明确条件→结果→选项”的短解释完成，不能只说“覆盖不同”“存在影响”，也不为展示推导而默认增加长数值演示。结论中的“直接／间接”“商品本身／后续传导”等会改变真假的边界必须明说，不让用户自行补条件。需要额外简化假设时明确标注，不能冒充题目给定。计算注明单位，最后回代／检查方向。先自行求解再核对答案；若已读过答案，仍重算，不能声称未看答案独立完成。
4. **辨析与迁移**：选择题说明正确项成立的条件及错误项混淆了什么；相同错误可合并说明。非选择题按尚未覆盖的误区选必要的条件变式，说明条件改变后答案为何改变，不必为每题编四个选项。用户的实际追问揭示新缺口时，先补该机制，并把它加入后续选题检查。

把考试可用的动作收束为“判条件 → 排除错误方向／口径 → 必要计算 → 校验”。能用符号、量级、反例或边界排除的，不做无助于选项判断的长推导；但不能只背关键词配答案。40 题／80 分钟平均每题两分钟，示范应让用户看得出考场实际要写哪几步。

遇到讲义或答案冲突，说明具体位置和条件，独立复核。OCR 中分母、负号、上下标或图形不清时检查原页，不静默修补后当成原文。没有合适原题时按现有材料继续讲解与明确标注的练习，进度记录来源缺口，不声称已补齐原题。

### ④ 秋明

用四条短句接通知识与题目，不再写第二遍讲义：

- **本质**：本模块处理什么，机制为什么成立。
- **识别与调用**：看到什么 → 先判断什么 → 从哪一关系起手。
- **防错**：最容易混的条件、单位或方向，如何排除。
- **串联与记忆**：接到哪一个已学概念／公式，哪一句要闭卷记住。

末尾状态只写“第 N 轮 k/总数｜本模块已讲解／尚缺…｜下一步…”。完整模块、快速回顾、待补来源与独立作答证据分别记录，不用“继续”或沉默推断掌握。

## 轮末秋高与跨轮记忆

轮末用约 **400–700 字**，完成三块：

1. 每模块一行“认题信号 → 第一步”，如实标待补项。
2. 用一条概念／公式主链和一组关键分岔串联本轮；解释为何条件改变就换结论，不单纯并排堆公式。
3. 合并本轮记忆卡为 **5–8 条闭卷提取提示**，至少涵盖易错条件。第 2–4 轮额外回扣前轮最相关的 1–2 点，不再全文重讲。

第 4 轮的秋高同时完成全范围收束：给出跨 Topic 的公式链、模型条件对照、仍需核对的薄弱点与精简考前记忆清单。不得另开必做第五轮才能“真正完成”。是否已经会做，只依据用户实际输出判断。

## 静默核查与续接

发送前自行检查，不输出审计表或夸大“全部掌握”：

- 四轮覆盖 Topics 1–7；缩短的是重复与例题数量，不是悄悄取消思想史、Gold、教材定义或课堂扩展。
- 零基础读者能否知道对象、单位、条件和常识原因？逐项追溯③用到的概念与公式是否已经在①②或此前教学中解释；有缺口就先补，不以“公式简单”跳过概念。
- 公式能否从定义或模型接起来？判断恒等式／行为式／均衡条件；因果结论是否注明模型；百分数、基年、国内／进口和现金／存款是否一致？
- 原题来源是否实际读过？是不是把教学题当真题、把近似当精确、把相关当必然、把已见答案当独立求解？计算与政策方向复核后再交付。
- 只读①②还可能在哪些题面上误用？相关课程材料已暴露的独立易错机制是否都用题面／反例检查过？每道新增题是否补了不同缺口，能否合并重复？不能把“有一道例题”当作应用覆盖充分。
- 逐题遮住解答检查：英文题面是否保留，能否知道已知什么、要算／判断／选择什么，并实际开始作答？选项是否完整，关键英文是否已解释并在题解中复现？缺少待求事项必须补成题；不能把解释或结论当作已出题。用户已明确理解的计算不重复，只修补缺失部分。
- 题目示范是否短而完整，记忆内容是否能复述？指标的定义、指标的数学变化与能推出的经济结论是否分清，是否漏掉权重或固定条件？历史年份、人物与市场案例以课程原件为据，只有确需当前信息时才另查权威来源。
- 材料整理、skill 制作和演示验证不算正式教学，也不复制 COMP2711 的学习进度。
